# מסמך דרישות מוצר ואפיון פונקציונלי (PRD) – מערכת דיווח שעות פעילות חודשית של"ח

**גרסה:** 2.1 מעודכנת

**קהל יעד:** צוות פיתוח, מנהלי מוצר ומעצבי ממשק (UI/UX).

---

## 1. מטרת המערכת ומאפיינים כלליים

המטרה היא לייצר מערכת ממשלתית קלה, מהירה ומאובטחת לדיווח שעות פעילות, שעות נוספות והיעדרויות עבור מורי של"ח.

- **עקרון עבודה:** התחלה עם מערכת פשוטה וידידותית (**MVP**), והוספת נדבכים ופונקציונליות מורכבת יותר בהדרגה.

- **חוויית משתמש ועיצוב:** נקייה מעומס ויזואלי, רספונסיבית לחלוטין (מובייל ודסקטופ) ומאובטחת ברמה גבוהה.

## 3. זרימת עבודה ותהליך אישור הדוח (Approval Workflow)

```
[1. מורה: מילוי הדוח, שמירת טיוטה ושליחה]
    │
    ▼
[2. מנהל/ת: קבלת קישור לדוח ──► אישור וחתימה / החזרה למורה עם הערות]
    │ (באישור)
    ▼
[3. מנחה: בדיקה ──► עריכה ישירה (הדגשה באדום) / הערות / החזרה למורה לתיקון]
    │ (באישור)
    ▼
[4. ממונה (רונן): בדיקה במסך ייעודי ──► העברה לתשלום / החזרה לעריכה (למנחה/מורה)]
    │
    ▼
[5. חיווי סטטוס סופי: מוצג למורה בתוך המערכת בלבד (כולל סימון שינויי מנחה)]

```

- **מדיניות עריכה מול החזרה במנחה:**
- **תיקונים קלים:** מבוצעים ישירות ע"י המנחה (השדות שעודכנו יודגשו בצבע שונה/אדום).

- **תיקונים מהותיים:** הדוח מוחזר למורה עם הערות מנחות לתיקון והגשה מחדש.

- **חיווי שינויי מנחה למורה:** במידה והמנחה ביצע שינויים ישירים בשעות, הדוח יציג למורה בלוח הבקרה סימון ברור (הדגשה ויזואלית והערה) המפרט את השעות המקוריות שדווחו לעומת השעות המאושרות לאחר עריכת המנחה.

## 4. אפיון מסכים וממשק משתמש (UI/UX)

### 4.1. מסך התחברות והזדהות (Login)

- הזנת מספר תעודת זהות ומספר טלפון נייד.

- אימות מול רשימת מורשים קבועה מראש במערכת.

### 4.2. מסך הגדרת פרופיל אישי (Profile Setup)

- **פרטים אישיים ומוסדיים:** שם מלא, ת"ז, היקף משרה (באחוזים), כתובת מגורים, סמל מוסד, שם המוסד, רשות מקומית, מחוז, פרטי מנהל/ת (שם ומייל), שיוך למנחה מחוזי.

- **מערכת שעות קבועה וימי שדה:** הזנת שעות הוראה קבועות לכל יום בנפרד (א'-ו') והגדרת ימי שדה קבועים בשבוע.

- **הסכמה לתהליך מקוון:** תיבת סימון (Checkbox) מחייבת שבה המורה מאשר כי שימוש במערכת ולחיצה על *שלח* מהווים חתימה דיגיטלית מחייבת. ללא סימון תיבה זו, לא תתאפשר כניסה למילוי דוחות.

### 4.3. לוח הבקרה של המורה (Teacher Dashboard)

- סיכום פרטי המורה ובית הספר.

- באנר חלון דיווח חודשי וכפתור יצירת דיווח חדש.

- טבלת מעקב דוחות קודמים: חודש, סטטוס, מזהה חתימה ותאריך.

- **מנגנון חיווי פנימי:**
- סטטוס הדוח מתעדכן בזמן אמת בתוך המערכת בלבד (ללא שליחת התראות במייל/**SMS** בשלב זה).

- הצגת הערות מנהל/מנחה/ממונה ישירות בממשק בעת החזרה לתיקון.
- אינדיקציה ייעודית לצפייה בשינויים שנערכו ע"י המנחה (שדות מודגשים).

### 4.4. מסך מילוי דיווח שעות חודשי (Monthly Report Form)

- **אוטומציה בלוח השנה:**
- תאריכי החודש וימי השבוע נטענים אוטומטית (ללא ימי שבת).

- סימון מודגש לימי שדה קבועים.

- חגים וחופשות משרד החינוך מוצגים ומודגשים אוטומטית בצבע ייעודי.

- **מבנה עמודות הטבלה:**
1. יום בחודש

2. יום בשבוע

3. **שעות עבודה קבועות (מפרופיל המורה):** עמודה לקריאה בלבד בצבע אפור להשוואה ואימות. *(השורה המסכמת העליונה מבוטלת)*.

4. שעות היעדרות (מספרי) + סיבת היעדרות (טקסט/בחירה).

5. שעות נוספות (הזנה ידנית בשלב זה) + סיבת שעות נוספות.

6. כיתה / שכבה.

7. תיאור הפעילות.

- **סך שעות חודשי:** שורת סיכום שעות (היעדרות, קבועות, נוספות) מוצגת **בתחתית הדוח בלבד**.

- **שמירת טיוטה וקבצים מצורפים:**
- כפתור שמירת טיוטה ומנגנון שמירה אוטומטית לחזרה מהנקודה שבה הופסק המילוי.

- רכיב ייעודי להעלאת קבצים/אישורים (**PDF**, **PNG**, **JPG** – אישורי מחלה, מילואים וכדומה) עד **10MB** לקובץ.

- כפתור הגשת דוח הנועל אותו ומעבירו לאישור המנהל/ת.

### 4.5. מסך אישור מנהל/ת (Principal Approval Page)

- כניסה מאובטחת דרך קישור ייעודי במייל (תצוגת אינטרנט של הדוח, ללא צורך בהתחברות או הורדת **PDF**).

- צפייה מלאה בפירוט השעות ובנספחים שהועלו.

- כפתור אישור וחתימה דיגיטלית בלחיצה, או כפתור דחייה/החזרה למורה לתיקון בצירוף הערות.

### 4.6. לוח הבקרה של המנחה (Supervisor Dashboard)

- טבלת ריכוז של כל מורי השל"ח המשויכים למנחה.

- **עריכת שעות ישירה בדוח:** אפשרות לשנות שעות ישירות בטבלה, כאשר כל שדה שנערך נצבע ומודגש באדום.

- הוספת הערות מילוליות לדוח.

- כפתור אישור והעברה לממונה, לצד כפתור החזרה למורה לתיקון במקרים מהותיים.

- כפתור ***ייצוא לאקסל*** לצורך ניתוח ובקרה.

### 4.7. מסך ממונה ייעודי (Ronen / Super Admin Dashboard)

- תצוגה מרוכזת של כלל הדוחות במערכת.

- יכולות סינון, מיון ובקרה מתקדמות.

- אישור סופי והעברת הדוח לתשלום.

- אפשרות להחזרת דוח לעריכה (למנחה או למורה) בצירוף הערות.

- כפתור ***ייצוא לאקסל*** מרוכז.

## 5. חוקים עסקיים, אימות נתונים ואבטחה

1. **חלון דיווח חודשי:** פתיחת הדיווח מ-25 לחודש הדיווח ועד ה-5 לחודש העוקב.

2. **חוק יום שדה גמיש:** חובת דיווח מוגברת בימי שדה (הזנת שעות נוספות מעל 0 או הזנת סיבה/נימוק).

3. **נעילת דוחות ואיפוס חתימות:** דוח שהוגש ננעל לעריכת מורה. החזרת דוח לתיקון פותחת אותו מחדש כטיוטה ומאפסת חתימות קודמות לשמירה על אמינות המסמך.

4. **חתימות דיגיטליות מאובטחות (**RSA** **2048**-bit):** חתימות המנהלים מבוססות מפתחות הצפנה אסימטריים בצד השרת.

5. **עמוד אימות חתימות ציבורי:** מאפשר בדיקה חיצונית של אמינות הדוח לפי מזהה דיגיטלי ייחודי.
